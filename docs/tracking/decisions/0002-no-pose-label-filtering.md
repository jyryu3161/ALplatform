# 0002. 기준 자세 기반 학습 라벨 검열 제거

## 맥락
버전 1은 도킹 자세를 기준 리간드와 비교해(MCS/RMSD, 수소 결합 임계값) 일부 화합물의 점수를 학습 라벨에서 검열했다. 이 검열은 모델이 배우는 목표 자체를 바꾸므로, 결과가 "도킹 점수 예측"인지 "기준 자세와 닮은 화합물의 도킹 점수 예측"인지 구분되지 않았다.

## 결정
성공한 도킹 점수는 기준 자세 RMSD, 수소 결합 유사도, 점수 부호와 무관하게 모두 학습 라벨로 쓴다. 기준 리간드는 상자 중심(중원자 무게중심)을 정하는 데만 쓴다.

## 대안
- **검열을 설정 옵션으로 남김**: 같은 파이프라인 이름의 결과가 서로 다른 학습 문제를 뜻하게 되므로 채택하지 않음.
- **자세 검증을 별도 분석으로 수행**: 파이프라인 밖에서 연구 단계별로 한다(재도킹, 자세 검토 등).

## 결과
- 버전 1 결과와 현재 결과는 학습 문제가 다르므로 프로토콜을 구분하지 않고 섞을 수 없다.
- 실패한 계산만 라벨에서 빠지며, 그 경우에도 점수를 지어내지 않는다.
- 자세 기반 검열을 파이프라인에 다시 넣는 것은 학습 문제를 바꾸는 과학적 방법 변경이며 사용자 결정이 필요하다.
