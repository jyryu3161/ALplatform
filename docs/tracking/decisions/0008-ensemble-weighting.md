# 0008. 앙상블은 모델 평균에 가중치, 검증 가중은 획득 관측 내부 분할로

## 맥락
TabM(멤버 k개), 트리(트리 수백 개), foundation 모델은 내부 구성원 수와 불확도의 의미가 서로 다르다. 여러 백엔드를 결합할 때 내부 구성원 수가 큰 모델이 결과를 지배하거나, 가중치를 정하는 데 평가 홀드아웃이 새어 들어가면 안 됐다.

## 결정
- 백엔드 하나는 내부 구성원 수와 무관하게 가중치 하나를 갖고, 가중치는 각 모델의 **평균 예측**에 건다.
- 결합 spread는 혼합 분산 `Σ w_m [σ_m² + (μ_m − mean)²]`의 제곱근으로, 모델 내부 퍼짐과 모델 간 불일치를 함께 담는다.
- `validation` 전략은 획득 성공 관측을 분자 그룹 단위로 한 번 나눠 각 모델의 탐색 학습(probe)을 하고, 검증 MSE(하한 1e-12)의 역수로 가중치를 정한 뒤, 모든 모델을 획득 관측 전체로 새로 학습한다. 평가 홀드아웃은 쓰지 않는다.
- 모델은 정해진 자원 안에서 순차로 학습한다.

## 대안
- **모든 내부 구성원을 하나의 풀로 합침**: 구성원 수가 많은 백엔드가 지배하므로 채택하지 않음.
- **홀드아웃으로 가중치 결정**: 보고 지표가 오염되므로 불가.
- **탐색 학습 모델을 그대로 최종 모델로 사용**: 검증 분할만큼 학습 데이터를 버리게 되어 채택하지 않음.

## 결과
- `validation` 전략은 사이클마다 모델 학습을 두 배 가까이 하므로 비용이 크고, 획득 그룹이 적은 초반에는 실패하거나 가중치가 불안정하다.
- TabFM처럼 spread가 0인 백엔드가 섞여도 모델 간 불일치로 결합 spread가 생긴다. 결합 spread는 선택 휴리스틱이지 보정된 신뢰구간이 아니다.
- 모델을 더 넣는다고 도킹 예측이 좋아진다는 보장은 없으며, 비교는 같은 시드·분할·초기 표본·예산에서 해야 한다.
