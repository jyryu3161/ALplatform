# 도메인 규칙

이 프로젝트의 도메인은 **도킹 예산이 제한된 풀 기반 능동 학습**이다. 화합물 풀에서 일부를 골라 점수를 얻고(질의), 얻은 점수로 회귀 모델을 학습해 나머지 풀을 예측하고, 예측으로 다음 질의를 고르는 일을 반복한다. 이 규칙들을 바꾸는 것은 과학적 방법의 변경이며 사용자 결정이 필요하다.

## 용어

| 용어 | 뜻 | 혼동 주의 |
|---|---|---|
| 점수(score) | 화합물 하나의 목표값. 도킹 모드에서는 Vina 계열 도킹 에너지(kcal/mol), replay 모드에서는 입력 CSV의 기록값 | **낮을수록 좋다.** 측정 결합 친화도가 아니다 |
| 풀(pool) | 질의 후보가 될 수 있는 화합물 집합 = 라이브러리 − 홀드아웃 | 라이브러리 전체와 다르다 |
| 홀드아웃(holdout) | replay 평가용으로 실행 시작 전에 봉인한 화합물 | 모델 내부 검증 분할과 다르다 |
| 내부 검증 분할 | 획득한 성공 관측 안에서 TabM 조기 종료·튜닝용으로 나눈 부분 | 홀드아웃과 무관 |
| 가중치 검증 분할 | `ensemble.strategy: validation`이 획득 관측 안에서 모델 가중치를 정하려고 나눈 부분 | 위 두 분할과 또 다르다 |
| 시도(attempt) | 오라클에 한 번 보낸 질의. 성공·실패 모두 포함 | 성공 관측 수와 다르다 |
| 사이클 0 | 초기 무작위 표본 | `learning.cycles`는 사이클 0 **이후**의 적응형 사이클 수 |
| spread / 불확도 | 선택용 경험적 퍼짐 값(점수 단위) | 신뢰구간·사후 표준편차가 아니다 |
| 분자 그룹 | 같은 정규 isomeric SMILES. 단, 평가 홀드아웃을 `split: scaffold`로 나눌 때만 같은 achiral Bemis–Murcko 골격(비고리 분자 전체가 한 그룹) | 입체이성질체는 서로 다른 구조. 내부 검증·가중치 검증 분할은 scaffold 모드에서도 구조 단위 |

## 라이브러리 구성

입력 행 하나 → `(ID 앞뒤 공백 제거, SMILES 파싱, 정규 isomeric SMILES, [replay면 점수 float 변환])`.

| 경우 | 처리 |
|---|---|
| ID 비어 있음 / SMILES 비어 있음 / 파싱 실패 / 점수 변환 실패 / 점수 비유한 | 이유(`missing_compound_id`, `missing_smiles`, `invalid_smiles`, `invalid_score`, `nonfinite_score`)를 기록. `invalid_policy: error`면 즉시 실패, `skip`이면 제외하고 계속 |
| 같은 ID, 같은 구조·같은 점수 | `duplicate_compound_id`로 제외 (항상) |
| 같은 ID, 다른 구조 또는 다른 점수 | `conflicting_compound_id` — `skip`이어도 **항상 실패** |
| 다른 ID, 같은 구조, 다른 점수 | `conflicting_structure_score` — 항상 실패 |
| 다른 ID, 같은 구조, 같은 점수, `deduplicate: true` | 사전순으로 가장 작은 ID 하나만 남기고(그 ID의 원래 행 정보 유지) 나머지는 `duplicate_structure`, `kept_compound_id`에 대표 ID |
| 같은 구조, `deduplicate: false` | 서로 다른 ID를 모두 유지 |
| CSV 문법 오류, 중복 헤더, 필드 수 불일치 | `skip`이어도 파일명·레코드 번호와 함께 실패 |
| 검증 후 남은 화합물 0개 | 실패 |

- 라이브러리는 항상 화합물 ID 순으로 정렬된다. 따라서 행·파일 순서를 바꿔도 대표 ID, 시드 기반 선택, 동점 처리가 바뀌지 않는다.
- 모델 입력은 구조에서 계산한 지문뿐이다. 점수, ID, 메타데이터 열은 절대 특성이 되지 않는다.
- 양성자화 상태·호변이성체·지정되지 않은 입체이성질체는 생성하지 않는다. 입력 SMILES의 화학 상태가 그대로 과학적 가정이 된다.

## 실험 수명 주기

1. **홀드아웃 봉인** (replay, `holdout_fraction > 0`): 분자 그룹 키를 정렬 → 시드 순열 → 그룹을 통째로 홀드아웃에 넣다가 `ceil(N × fraction)`에 도달하면 멈춤. 최소 한 그룹은 풀에 남긴다. 그룹이 2개 미만이면 실패. 실제 비율은 요청과 다를 수 있다. 홀드아웃 후 풀이 3개 미만이면 실패.
2. **사이클 0**: 풀에서 `min(initial_size, 남은 예산, 남은 풀)`개를 시드 무작위 비복원 추출.
3. **적응형 사이클 c (1..cycles)**: 질의 수 = `min(learning.batch_size, 남은 예산, 남은 풀)`. 직전 사이클 모델로 남은 풀 전체를 예측한 뒤 선택 규칙 적용.
4. **각 사이클 끝**: 지금까지의 성공 관측 전부로 **새 모델을 처음부터** 학습(시드 = 실험 시드 + c).
5. **종료**: 다음 사이클 시작 전에 `남은 예산 ≤ 0` 또는 `남은 풀 = 0`이면 멈춤, 아니면 사이클 상한까지 진행. `summary.stop_reason`은 `budget`(시도 수 ≥ 예산) → `pool_exhausted` → `cycles` 순서로 판정.

불가능한 전이:
- 이미 질의한 화합물은 다시 선택될 수 없다(성공·실패 무관).
- 홀드아웃 화합물은 질의될 수 없다.
- 성공 관측이 3개 미만이면 학습 단계에서 실험 전체가 실패한다(사이클을 건너뛰지 않는다).

## 예산과 실패

- 예산 = **시도한 화합물 수**의 상한. 초기 표본과 모든 실패를 포함한다.
- 도킹 실패(리간드 준비 실패, 분리된 SMILES, 엔진 오류, 시간 초과)는 `status: failed`와 오류 문자열로 기록되고 예산 1을 소모한다. **실패한 화합물에 점수를 만들어 넣지 않으며 학습에도 쓰지 않는다.**
- 오라클이 성공이라면서 점수가 없거나 비유한이면 실험 전체가 실패한다.
- 성공한 점수는 기준 리간드 자세 RMSD, 수소 결합 유사도, 점수 부호와 무관하게 모두 유지된다.
- 도킹 점수 = 생성한 모든 형태(conformer) 중 가장 낮은 유한 에너지. 동점이면 낮은 형태 번호.

## 학습 데이터 규칙

- 학습·튜닝·조기 종료·표준화·가중치 결정·문맥 선택에 들어가는 데이터는 **획득한 성공 관측뿐**이다.
- 홀드아웃 라벨은 학습, 목표값 표준화, 튜닝, 조기 종료, 가중치, 선택 어디에도 들어가지 않는다. 홀드아웃 라벨을 바꿔도 질의 순서·학습 기록·예측이 바뀌면 안 된다.
- 모든 내부 분할(TabM 내부 검증, 가중치 검증)은 같은 정규 구조 단위로 나누며, 같은 구조가 양쪽에 동시에 들어가지 않는다. 평가 홀드아웃이 scaffold 분할이어도 내부 분할은 골격이 아닌 구조 단위다(같은 골격의 서로 다른 구조는 내부 학습·검증에 나뉠 수 있다).
- TabM 목표값 표준화: 내부 학습 행만으로 평균·모집단 표준편차 계산. 표준편차가 0이면 1.
- TabM은 서로 다른 분자 그룹이 2개 이상 있어야 학습한다. 가중치 검증 앙상블은 신경망/foundation 멤버가 있으면 3개, 트리만이면 2개 이상의 그룹이 필요하다.
- foundation 모델 문맥: 성공 관측에서 최대 `max_context_samples`(기본 2048)행을 시드 비복원 추출한 뒤, 그 문맥 행에서만 분산이 큰 순으로 `max_features`(기본 128)개 비트를 고른다(동점은 결정적). 질의 행과 홀드아웃은 이 선택에 쓰이지 않는다. 문맥 행이 2개 미만이거나 변하는 비트가 없으면 모델 할당 전에 실패.

## 선택 규칙 (점수 최소화)

남은 풀 각 화합물의 예측 평균 μ, spread σ에 대해:

| 전략 | 선택 기준 (작은 값 우선) |
|---|---|
| `random` | 시드 균등 난수 |
| `greedy` | μ |
| `lcb` | μ − β·σ |
| `thompson` | 화합물마다 독립 N(μ, (β·σ)²) 표본 하나 — 사후 표본이 아닌 휴리스틱 |

- 동점은 라이브러리 위치(= ID 사전순)로 깬다.
- β 스케줄 (적응형 사이클 c, 설정된 사이클 수 C, f = (c−1)/(C−1), C=1이면 f=0):
  - `constant`: β_c = β
  - `linear`: β_c = β + (β_final − β)·f
  - `exponential`: β_c = β·(β_final/β)^f, β와 β_final 모두 양수 필수
- 스케줄은 설정된 C 기준이라 조기 종료하면 뒤쪽 값은 쓰이지 않는다. 각 사이클의 실제 β는 `acquisition_beta`로 기록되고 사이클 0은 null. `greedy`·`random`은 β를 무시한다.

## 앙상블 결합

모델 m의 평균 μ_m, spread σ_m, 정규화 가중치 w_m(합 1):

```text
mean    = Σ w_m μ_m
spread² = Σ w_m [σ_m² + (μ_m − mean)²]
```

- 백엔드 하나는 내부 멤버 수와 무관하게 가중치 하나를 가진다.
- `mean`: 균등. `weighted`: 사용자 가중치(유한·음이 아님·합 양수)를 `models` 순서대로 정규화. `validation`: 가중치 검증 분할에서 각 모델을 따로 학습해 MSE를 구하고, MSE를 1e-12로 하한 처리한 뒤 역수에 비례하게 정규화. 그 후 모든 모델을 획득 관측 전체로 새로 학습한다.
- 백엔드별 σ: TabM은 공유 멤버 간 모집단 표준편차, 트리는 트리 예측 간 모집단 표준편차, Nori/TabLDM은 분위수로 근사한 표준편차, TabFM은 **항상 0**. 그래서 TabFM 단독이면 `lcb`·`thompson`이 사실상 `greedy`가 된다. σ = 0을 확신으로 해석하지 않는다.

## 평가 지표

- 홀드아웃 회귀 지표: RMSE, MAE, R², Spearman. 정의되지 않거나(표본 2 미만, 상수 벡터) 유한 입력에서도 넘치는 값은 null.
- 발견 지표 (replay 전용, 풀 기준; N = 풀 크기, K = min(top_k, N), m = 획득 수, h = 획득 중 참 상위 K 적중 수):
  - top-K recall = h / K
  - enrichment factor = (h / m) / (K / N), m = 0이면 null
  - simple regret = 획득 최저 점수 − 풀 최저 점수
  - 참 상위 K의 동점은 ID로 깬다. 홀드아웃은 계산에서 제외한다.
- 도킹 모드는 풀 전체의 참 점수가 없으므로 `holdout_fraction: 0`이 필수이고 발견 지표를 내지 않는다. 관측 점수와 실패만 보고한다.
- TabM 튜닝 점수·가중치 검증 MSE는 모델 선택 통계이지 편향 없는 시험 성능이 아니다. 홀드아웃 곡선으로 하이퍼파라미터를 고른 뒤 그 홀드아웃을 "손대지 않은 시험 세트"라고 부르지 않는다.

## 재현성

- 같은 설정·같은 시드·같은 소프트웨어/하드웨어 환경에서 두 번 실행하면 질의 순서, 점수, 예측, 불확도, 분할, 지표, 학습 기록, 요약, 포즈 파일 바이트가 수치 허용 오차 없이 같아야 한다. 시각과 출력 경로 접두어만 비교에서 제외한다.
- 시드 함수 s(a, b, c) = SHA-256(JSON `[a, b, c]`, 공백 없음)의 앞 4바이트를 big-endian 정수로 읽어 `mod (2³¹ − 2) + 1`.
  - 화합물 시드 = s(실험 시드, 화합물 ID, SMILES) — ETKDG 형태 생성에 쓴다.
  - 형태 i의 도킹 엔진 시드 = s(화합물 시드, `str(i)`, SMILES).
  - 따라서 평가 순서나 `docking.workers` 수가 결과를 바꾸지 않는다.
- 앙상블 멤버 시드 = (모델 시드 + 멤버 순번) mod 2³².
- PyTorch/CUDA 버전이나 장치가 다르면 별개 환경이다. 다른 환경 간 결과 차이는 재현 실패가 아니다.
- `model.inference_batch_size`를 바꾸면 검증 손실과 예측의 마지막 자릿수 반올림이 달라질 수 있다. 비교할 실행끼리는 같은 값을 쓴다.
